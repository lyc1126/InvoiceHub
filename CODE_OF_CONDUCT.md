# Code of Conduct

## Our Standards

We expect respectful, technical and good-faith collaboration. Harassment,
discrimination, threats, deliberate disclosure of private information, and
disruptive conduct are not acceptable.

## Scope

This policy applies to project spaces, events, pull requests, issues, reviews,
and private communication about project work.

## Reporting and Enforcement

Report conduct concerns privately to the repository owner through the GitHub
profile in repository metadata. Reports will be handled as confidentially as
practical. Maintainers may request changes, remove content, temporarily limit
participation, or permanently restrict participation depending on severity and
context.

Retaliation against a person who reports a concern in good faith is not
acceptable.
