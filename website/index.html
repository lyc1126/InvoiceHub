A FEW GOOD QUESTIONS

开始前，
你可能想知道。

发票需要上传到云端吗？

核心发票识别、汇总和成本分析在本机运行。官网演示不会读取你的本机文件。软件的更新检查会联网；如另行配置 OCR 服务，其数据处理范围需按该服务配置确认。

支持哪些文件和系统？

共享核心支持 PDF、OFD 和 XML。项目面向 Windows x64 与 macOS Apple Silicon 开发，当前处于开发预览阶段；可下载产物、运行前提与平台验证状态，以公开仓库 README 和 Releases 为准。

关闭窗口后，还会继续整理吗？

启动独立监控后，关闭浏览器不会停止监控。停止页面服务与停止监控是两个独立动作，可按需要选择。

它能自动完成正式做账吗？

项目已有本地凭证预览、人审与批次协议的开发基础。真实账套操作仍有独立的资料核对与授权要求，不能把演示或代码测试理解为自动完成正式入账。

可以参与开发或自己部署吗？

可以按 AGPL-3.0-or-later 许可证使用和修改源码。当前产品是单用户本地工作台；开发、运行和贡献步骤见仓库文档。分享反馈时请勿附带真实发票、公司资料或凭据。
