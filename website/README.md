# InvoiceHub 官网

独立静态官网，使用 `Hi / hi` 品牌语言、原创纸票画布视觉和本地交互演示。中文内容以公开仓库产品边界为依据；展示汇总、预览、批量打印、项目明细、成本参考、自适应单据和独立监控。OCR 标注已有配置入口、做账标注本地流程开发中、税率计算器标注官网概念预览，不承诺正式 OCR 运行包、自动入账或识别准确率。

## 浏览与维护

直接打开 [index.html](index.html) 即可浏览，无需安装依赖、启动 Python 后端或读取本机运行配置。全部脚本、图标和字体位于本目录内。

软件运行时，「设置 → 关于 → 官方网站」使用当前 localhost 的 `/website/` 打开本目录的随包资源，无需公网服务器；该模式下导航显示「返回工作台」，回到 `/settings#about`。直接打开 HTML 或公网部署仍显示原「开始使用」。固定远端更新 Feed 不随官网入口改动。

`src/invoice_hub/website.py` 的白名单包含 10 个页面资源及许可证，是 HTTP、Core Build ID、源码快照与 Windows/macOS/Tauri 组装的共同输入。新增被页面引用的文件时须同步清单，不能递归公开维护脚本、测试或 README。已有安装包需要后续构建才能带入该入口。

需要独立 HTTP 预览时，可启动只暴露本站目录的可选预览服务：

```powershell
node website/scripts/preview.cjs 4173
```

浏览 `http://127.0.0.1:4173/`。如端口已占用，显式传入另一个端口；不会改变 InvoiceHub 软件的固定业务端口。终端中的 `Ctrl+C` 停止预览。该服务仅用于开发，不是生产服务器。

- `index.html`：品牌、产品、工作流、开源入口与 FAQ；GitHub 链接与 `src/invoice_hub/version.py` 的公开地址一致。
- `style.css`：荧光黄绿、墨黑、纸白与克制的珊瑚色；响应式布局、表格、弹窗、减少动态效果。
- `paper-scene.js`：两张票纸、三个标签分别缓存为离屏 Canvas；指针进入票据区域时独立展开，离开归拢，键盘与触屏支持切换。30 fps 上限，静止、屏外与后台停止调度，手动暂停和系统减少动态效果。
- `demo-data.js`：明确的合成数据与演示计算；与生产解析、成本算法和 API 完全独立。
- `app.js`：四视图标签、筛选、排序、同票合计、逐行加价率、CSV、逐份预览与放大、打印动画、分组明细与 TSV、入/出库动态行、做账阶段和概念税额换算。演示打印只显示动画，不调用系统打印。
- `assets/`：本地字体、原创建站图标与精选 Lucide 图标；来源见 [ASSETS.md](ASSETS.md)。

脚本以经典 `defer` 方式加载以兼容直接打开 HTML。修改资源时同步修改 HTML 的 `?v=` 参数。可直接将本目录中的页面资源部署到静态托管的根目录或 `/InvoiceHub/` 子目录。预览脚本、测试与维护文档不需要上传。部署不得覆盖现有 `updates/` Feed；本次未配置部署或发布。

验证前假设与停止条件：

- 本地官网入口在原有软件服务器上完整加载；最小样本为隔离空目录配置、正式根 BAT 的 Development/NoBrowser 启动、首页/health、设置及恢复入口、官网和 10 个资源。核对新脚本版本、字节内容与返回路径；任一失败只修对应环节，通过后停止测试实例，不读取真实默认配置。
- 离线资源清单同时参与 HTTP、组装和 Build ID；用精确复制、一个缺失字体样本、一个维护文件拒绝样本及源码/alpha 暂存 Build ID 一致性决定是否修订清单，不重打成品。

- 桌面与手机可清楚显示品牌和下一节提示；用 1440×900、390×844、375×667 和横屏观察。任一横向溢出或文字遮挡时仅修订对应布局，布局通过即停止该类别。
- 同票 PDF/XML 在合计中只计一次；用固定演示家族、筛选后失效选择和缺失金额做最小样本，结果决定是否修订演示逻辑。
- 本地演示无需访问生产 API；检查页面请求、导出内容、脚本和预览根目录边界。若触碰软件状态或业务文件则停止并修复隔离。
- 画布在支持时非空、运动可暂停；在减少动态效果下保持静态，无法绘制时保留文字品牌。使用画布像素、按钮状态和截图验证。
- 独立图层只响应票据区域，进入/离开后收敛并停止帧调度，减少动态效果时直接切换构图。Node VM 调度测试可检查状态和停止条件，但不证明实际像素、鼠标命中区域或视觉效果。
- 打印演示只在全部家族存在同票 PDF 时放行；明细分组保留税率/规格/单位边界，缺明细不能用票头金额补齐；换算金额以整数分和 BigInt 四舍五入，结果必须满足未税加税额等于含税。
