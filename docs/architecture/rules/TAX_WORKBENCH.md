## 税务工作台与税务计算器规则

- 完整税务工作台仍是设计阶段：其真值为[交互与架构设计](../../TAX_WORKBENCH_DESIGN.md)、[算法与政策规格](../../TAX_ALGORITHMS_AND_POLICY.md)和独立合成[原型](../../design/tax-calculator-prototype.html)。它们不注册 API、不读取公司资料、不进入 `web/` 或包资源清单；旧计算器 MVP 只保留在本机草稿，不属于 `main` 能力，也不得当作已验收基线引用。
- 按 D0—D5 分阶段实施，每阶段独立分支、独立验收，前一阶段集成后再开展依赖它的功能。正式实现时必须在同一阶段同步 API、前端消费、静态版本参数、build/package data 与握手能力清单；源码界面验证不等于双平台成品、原生窗口或申报结果。
- 金额、数量、税率一律以十进制字符串进入 Python `Decimal`；不得使用 JS `Number`、API float 或动态 `eval`。`null` 表示未知，只有“已确认当期无该事项”才是有证据的零。票面税额不是当期应纳，测算、已申报和已缴是三种独立状态；计算器不执行申报、付款或账套写入。
- 解释与结果必须同源：正面数字与背面解释来自同一次运行的 `CalculationTrace`，前端不得重算；解释失配必须阻断该结果，规则、快照或输入变化后旧结果与旧解释同时失效，且退出小计。
- 公司资料绑定是独立于 `TargetProfile` 的显式事实，默认为空；为空时不得读取当前 `watch_dir`、最近目录、父目录或会计软件。原生选择器只回填待保存草稿，检测与保存后才授权读取；切换 `watch_dir` 不得隐式改变税务公司，两者不匹配时禁止票据跨公司交接。
- 自定义税率固定标记 `user_assumption`，不得显示为官方适用规则、不得静默回退预设值、不得绕过资格校验；纳税人身份、小微、六税两费和教育费免征等资格必须逐项取证，未核实不得生成自动结论。
- 规则包必须由税务内容复核者确认适用范围、文号、有效期、公式和解释模板，并记录 `verified_at/coverage_through/review_status`，不能因为法律没有明确终止日就承诺无限期已核验。旧草稿中已核实的错误规则（营业账簿按本、宽泛产权税目、起征点比较符、过期依据等）必须在 D0 删除或替换，预期值取官方正文与独立手算，不得从被测实现反推。
- 只读归集不授权账套写入或报税；不得向页面返回内部绝对源路径，以 opaque evidence ID 展示相对名称和页/行定位；敏感数据不进入公共日志、源码、截图或测试夹具。
- 政策来源分级：只有 A 级官方原文（法律法规、财政部与总局公告及规范性文件）可以进入规则包；政策解读、答问、地方口径和电子税务局提示只产生待核对提示；咨询快讯只作线索；视频号与自媒体只进线索箱，永不进入计算链、解释模板或包产物。线索必须回溯到 A 级原文并完成签署后才能成为规则。
- 测算到申报之间的三项交付物与算法同等对待：申报表映射（绑定表式版本，改版后旧映射必须 stale 而不是继续显示行次）、征期与申报期限（记录来源与核对日期，未核验不显示推算日期，期限只作提醒不构成已申报证据）、留存备查清单（来自本次实际引用的规则与证据，不是通用模板）。
- 税费种认定是“这家公司该报哪些税”的第一判据，由用户导出或录入，不由目录内容反推；纳税人身份、优惠资格和认定信息以带生效期间的版本化事实保存，历史期间回放当时状态，不允许用今天的身份计算以前的属期。
- 输出边界：不生成税收筹划或节税方案，不替用户在多种口径中选择“更省税”的一种，不把测算表述为“应当缴纳”；风险提示只做事实对照。进项转出与分摊首轮不做自动计算，只接受已确认金额或返回 `needs_review`。
- 投入开发前按[价值评估与就绪度](../../TAX_WORKBENCH_VALUE_AND_READINESS.md)重新评估，并先写假设与停止条件。旧 MVP 草稿源码不在本工作树、stash 或 Git 历史中，D0 不得假定可直接迁入：先定位只读核对，不可得则按规格重新实现并用独立预期验收。
- 政策中心的交付形态只允许订阅提示、覆盖声明与版本差异，不自行撰写结论或解读；漏报必须可通过覆盖声明与可达性状态被检验，不得用“无更新”掩盖采集失败。没有固定复核人力时退回“不解读、只提示、只覆盖 A 级来源”的最小形态。

## 工作区 B8 手工基础（2026-11-17）

公司根税费记录与显式手工场景可按 P2 接入，不解锁政策自动计算。只接收十进制字符串/null，零需来源；申报、缴纳、测算独立。仅普通一般计税四项已确认输入可运行，按历史身份、月度正额与连续留抵校验，同一快照产生结果/解释；没有规则复核、表式映射/征期时不得生成对应结论。未知写响应只查询完整记录，不能自动重放或更新旧草稿。完整税务工作台阶段门禁继续适用。
