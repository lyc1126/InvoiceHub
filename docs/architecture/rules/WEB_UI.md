## 接口、资源与交互

- 经典首页局部刷新（2026-11-22）：相同来源和内容的行在 SSE/读取后复用 DOM，行身份必须同时包含目标、位置键与源路径，临时结果转完整时重置可操作阶段；全选/清空只同步复选框属性，不重建表格。保留未变化行的焦点、内部滚动和未保存目录草稿；筛选/排序仍取后端全量结果，旧代次不回填。合成回归与指定重绘故障检出见[运行说明](../../BROWSER_E2E.md)，本机 Chrome 与 GitHub Linux/配套 Chromium 的结果分别记录。
- 读取失败后恢复必须替换过期的失败提示；有目录草稿时同时说明“待保存目录尚未生效”，不得覆盖草稿，也不能因抑制例行成功提示而让恢复后的数据仍显示读取失败。

- 产品反馈（2026-11-19）：设置 › 关于的“建议与反馈”打开 Vue WsModal，默认不带环境，先预览且明确同意公开；不自动读取/发送发票、日志、路径、配置或附件。客户端不能携带 GitHub 写凭据；中转只在显式提交后访问。未知结果锁定重复提交，只查询同一回执；未配置服务时明确未开通，不伪装成功。构建身份四项默认折叠“技术详情”，保留手动展开用于诊断。协议与上线边界见[反馈设计](../../FEEDBACK_DESIGN.md)。

- 修改后端接口、服务返回结构、生成产物字段或业务状态语义时，必须同步更新：
  - 前端页面
  - 前端 JS 消费
  - 页面文案
  - HTTP/静态契约测试
- 修改 `web/static` 下的 CSS/JS 后，必须同步更新引用该资源的模板版本参数（例如 `?v=...`），并在前端静态契约测试中锁定新版本号；不得只改静态文件而不刷新版本，避免浏览器缓存导致用户端看不到改动。
- 修改 `web/static`、前端模板或皮肤 CSS 后，收尾前必须验证当前正在运行的 localhost 已实际应用本轮前端资源：至少检查目标页面 HTML 中的新 `?v=` 参数、对应静态文件内容、`GET /api/v1/health` 指向当前仓库运行态，并用浏览器或等价 DOM 检查确认关键样式/脚本计算结果已生效。若当前 localhost 未加载新版本、端口指向旧进程或浏览器仍展示旧资源，必须先用正式启停入口重启并复验，最终回复需明确说明是否覆盖当前启用皮肤与 `?no_skin=1` 恢复入口。
- 首页原生目录选择器返回的路径是待保存草稿，页面必须明确显示“待保存目录”；自动刷新、SSE 重连或列表刷新不得覆盖用户尚未保存的输入框路径。
- 所有使用 `EventSource` 的页面都必须同时处理 `onerror` 和重连后的 `onopen`：断线给出用户可见状态，重连后刷新关键数据。
- 用户可见按钮必须区分“普通禁用”和“异步处理中”：只有真实请求、选择器、重建、打开文件等进行中状态可以显示等待光标；无待保存草稿、未选中行、功能不可用这类普通禁用态不得使用加载光标。
- 表格必须保持真实 `<table>` 结构和可选择文本；调整表格渲染时必须保留可粘贴到 Excel/WPS 的 TSV 复制路径。
- 首页、成本页等内部可纵向滚动的子表容器不得用纵向 `overscroll-behavior: contain` 阻断滚动链；当子表滚动到上/下边界且主页面仍可滚动时，继续滚轮或触控板滚动必须交给主页面滚动条。
- 悬停/聚焦浮层（如成本页算法说明）不得只靠固定 `left/right` 锚点：按钮位置会随工具栏换行与布局调整变化，必须在显示时按视口测量并夹在可视区内、避开吸顶导航，空间不足时翻转方向或限高内部滚动；CSS 默认值只作无 JS 回退。
- 普通导航面向日常用户；`/backend` 可保留直达诊断，但不得重新暴露到用户第一视图导航，除非用户明确要求。

## 单据索引与批量入库

- 渐进候选必须显式区分临时与完整结果：入库列表可先于出库索引可用，首页批量入库只准备所选票；临时出库预览不能导出，完整索引就绪后须重新预览。export-status 可复用签名有效的文件名元数据，正式导出的实时校验不能被缓存替代。
- 首页服务端分页仍按全量结果筛选、排序和统计，全选覆盖完整筛选结果；首次临时结果禁止勾选和正式操作，不能把不稳定行位置当成完整投影身份。完成或目录变化时切换代际，迟到请求不得覆盖新页面。

- 单据大目录索引必须在可终止独立进程执行，保存/校验目录不得在 API 事件循环全量解析。缓存按 TargetProfile/目录隔离且只作派生信息，停止保留已完成解析，旧 job_id 不得停止新任务；出库预览/导出仍实时校验来源目录和号码。首页及单据列表必须有界渲染，分页不能缩小完整筛选结果的全选范围。解析字段语义变化时必须递增单据缓存版本。
- 首页批量入库交接仅传当前 `target_id + invoice_key + source_path` 草稿，服务端在核对和逐票导出时重验活动目录及真实源文件；目录切换必须使队列失效。已有文件仅显式跳过或导出副本；网络结果未确认不得自动重试。单据读取成本 CSV 时，仅完整明细一致的不同来源可折叠，来源内重复明细必须保留，冲突必须阻断且不得重写成本真值。

## 首页勾选合计

- 首页勾选发票合计必须按同票家族去重：优先使用当前发票号码，其次使用文件名中的 20 位号码，最后按源文件路径区分；票头与文件名取得的同一号码必须落入同一号码命名空间。三项金额必须分别从票头 `除税价 / 税金 / 开票金额` 累计合法金额；同一家族同字段存在多个不同合法金额时，该字段整张票不计入并明确提示冲突。
- 首页勾选合计请求必须同时携带并校验 `invoice_key + source_path`，位置键已对应其它源文件时必须返回过期选择，不得误汇总。合计成本明细只能只读当前 `watch_dir/成本发票明细.csv`，不得触发重建或反推票头金额；匹配优先发票号、无结果再回退源文件，并按 `内部项目名称 + 明细税率` 拆组、按 `规格型号 + 单位` 汇总，缺失税率必须显示未识别，不得用票头税率猜测。

## 原票预览与打印

- 源文件预览的 15 分钟有效期必须是闲置超时，不得在预览弹窗仍打开时按创建时间硬切断；弹窗打开期间必须轻量续租，内容访问必须刷新闲置期限，定时器被节流、后端重启或 job 回收后的 `404/410` 必须先尝试自动重建原勾选会话并保留当前文件/页码。关闭弹窗必须停止续租；不得因续租放宽源文件变更、目录切换、作业数或缓存上限。
- 首页源文件预览只能接收当前发票列表已勾选的 `invoice_key + source_path`，服务端必须用当前列表重新校验身份并确认解析后的真实文件仍位于当前 `watch_dir`；不得增加任意本机路径参数、目录浏览器或把绝对路径返回浏览器，多选预览保留每条源文件且不按同票家族去重。
- 源文件预览是原生内容镜像，不是发票字段解析：PDF/OFD/受控图片只返回 PNG 页，XML 只以安全纯文本返回，其它格式只展示元信息和系统打开入口；SVG 必须拒绝 DTD、实体、脚本、事件、主动元素和外链资源，XML/HTML/SVG 等本地内容不得进入前端 `innerHTML`。
- OFD 预览必须使用真实页面树和专用渲染组件，不得把 ZIP 内图片枚举或 MuPDF 对压缩包的读取当作 OFD 排版支持。组件输入、Java 21 和依赖必须锁定并绑定核心源码指纹；保留包内字体优先、页面/模板字形检查与渲染告警阻断，不能将已知缺字/漏图票面当成功。子进程必须有超时、内存/并发上限、独立临时解包与文件/网络权限边界；Java 版本升级不能跳过限制策略复验。组件缺失只影响 OFD 条目，不能阻断混选的 PDF/XML；印章显示不等于签名验真。 ZIP 安全检查必须读取 `ZipInfo.orig_filename`，不能使用已经替换 Windows 分隔符或截断 NUL 的 `filename`。 组件完整性缓存必须在目录、清单或任一成员元数据变化时失效并重新核对；不得反复全量哈希每页，也不得永久信任已经变化的组件。
- 预览作业必须短期、仅内存、按需渲染并受记录数、页数、像素、单作业/全局字节和过期时间约束；切换 `watch_dir` 时与打印缓存一起清空，不得把预览内容写入源目录、普通/成本投影、runtime 文件或 SQLite 发票主数据。
- 首页勾选汇总或源文件预览弹窗打开时，必须同时锁定 `html` 与 `body` 的背景滚动；不能只锁 `body`，因为皮肤对根元素设置 `overflow-x` 后会阻断滚动锁向视口传播，导致窄屏保留根滚动条并可滚动弹窗后的页面。
- 首页批量打印必须使用 `invoice_key + source_path` 重新校验勾选身份，并按同一 20 位发票号码家族只打印一次；只能读取当前 `watch_dir` 内仍存在的 PDF 票面，选中 OFD/XML 时允许回退同票家族 PDF，没有可用 PDF 必须整批失败并明确提示，不能静默漏票或把文件名/汇总表重建成票面。
- 浏览器打印准备只能生成有时限、有页数和内存上限的进程内票面快照，不得写入 `watch_dir`、普通/成本投影或 SQLite 发票主数据；原 PDF 每一页都必须保留并独占一张打印纸，不能为了“一票一页”丢弃多页发票的后续页。
- `window.print()` 只能请求浏览器打开系统打印对话框；页面必须覆盖弹窗被拦截、浏览器无打印 API、PDF 渲染失败、票面加载失败和作业过期等可诊断错误，但不得把“对话框已打开”表述为“实体打印成功”，因为浏览器不会向页面可靠暴露用户取消、打印机离线或纸张输出结果。
- 打印页首次自动调用 `window.print()` 前必须等待全部票面图片完成 `load + decode` 并至少经过两次浏览器渲染帧；命名 `@page` 只允许声明横/纵方向，纸型必须沿用打印机或用户选择，打印盒必须使用页框百分比尺寸跟随实际页框，不得用固定 A4 毫米尺寸或打印态 `100vw/100vh` 形成纸型覆盖与预览重排反馈；只允许在第二张及后续真实票面前强制分页，避免首次预览空白、持续跳动和末尾空白页。

## 皮肤系统

- 皮肤系统默认必须是“无皮肤”且可恢复；普通页面可加载当前皮肤，`/backend` 不加载皮肤，必须保留 `?no_skin=1` 作为皮肤损坏时的恢复入口。
- 默认浅色与官网 `website-dark` 共用现有皮肤状态；明暗切换必须先加载样式、再保存并切换，保留页内草稿和勾选，失败可重试。首屏皮肤身份必须早于 body 绘制；`?no_skin=1` 固定浅色且不改写保存状态。单据和源票面不得因深色外观反色。
- 皮肤 ZIP 只允许 `skin.json`、CSS 和静态资源；`skin.json` 必须声明 `id/name/version/entry`，`id` 只允许小写字母、数字和短横线。不得导入或执行任意 JS、HTML、脚本、可执行文件或远程资源。
- 皮肤导入必须校验 zip slip、绝对路径、Windows 盘符路径、`..`、重复文件、符号链接、加密 ZIP、文件数和大小上限；CSS 必须拒绝 `@import`、外链 URL、`data:`、`javascript:` 和包内不存在的资源引用。
- 导入皮肤只能写入 `runtime/local_state/skins` 这类运行态位置，不得写入 `watch_dir`，不得污染源发票、成本产物或默认配置；内置皮肤只读，同 ID 导入不得覆盖内置皮肤。
- 新增内置皮肤必须只覆盖 CSS 变量和既有选择器，不能改变业务 DOM、表格结构、TSV 复制链路、SSE 重连、目录草稿或成本输入行为；引用第三方项目时只能作为视觉参考，除非许可和来源已明确记录，否则不得复制素材、字体包、组件代码或源码样式。
- 内置皮肤允许打包本地字体子集和原创图片纹理，但必须使用包内相对 `url()`、记录来源/许可、禁止远程字体和外链图片；不得复制官方游戏素材、角色、Logo、截图或商业字体。

## 临时识别

- 临时原文件预览只接受原生选择产生的 id 或所属历史线程 item；不得接受任意路径。复用受限 PNG/纯文本渲染，每次返回前后校验来源；历史任一成员失效不能通过预览绕过。关闭/切换停止复核并释放 blob URL，迟到页内容不能覆盖新文件；操作按钮不得进入 TSV。

- 临时批次只处理显式选择的 PDF/OFD/XML，不扫描其父目录，不改变活动 TargetProfile、monitor 或正式投影；图片/纯扫描件明确提示 OCR 未支持。
- 历史是关联原文件的可重建缓存，任何来源移动、删除、替换或内容变化时禁止展示旧线程明细；复制也必须复核。删除历史不能删除源文件。
- 普通浏览器无法提供源文件完整路径时，通过原生多选确认；不得把上传副本的存在当成原文件仍存在。桌面原生拖入只交给固定 localhost 经典首页或 `/workspace/temporary`（含尾斜线），其它模块拒绝，不向 Web 暴露私有 token。
- 弹窗保留草稿、支持键盘排序/Escape、减少动态效果；关闭/切换视图后的迟到结果不能覆盖当前视图。后台识别不阻塞页面与普通数据读取。
- Vue 临时识别复用同一 API / worker / 缓存，不能另存票据真值；切换模块保留队列与设置草稿，隐藏时停止轮询并清空未复核的结果 / 预览，返回后重新校验。运行任务与当前展示历史可能不同，两者必须同时轮询；其它任务源失效不得清掉当前有效历史。复制前重验全部来源，TSV 不含操作列；创建响应未知只提示读取历史，不自动重提。预览 XML 只作纯文本，blob 在切换 / 隐藏 / 卸载时释放，旧请求与超时不得取消或覆盖新文件。

## 勾选删除、来源追溯与大批预览

- 删除所选源文件必须先生成确认清单，用户可取消或确认移入系统废纸篓/回收站；只包含实际勾选路径，不连带处理同票家族其它格式。活动 target、记录键/路径及源签名必须重新验证，链接路径拒绝；与 monitor 同步写锁互斥。原生回收失败时停止，不允许永久删除回退。
- 删除前持久化逐文件意图、后保存观察；响应未知只查询已有job，重启与重复确认都不能自动重做。部分完成必须逐文件显示已处理/未处理/待核对，不能笼统称全部成功；自动同步仍只维护投影与状态，保留手改覆盖。
- 汇总明细搜索和税率筛选不得改变顶部全部勾选金额口径；每组来源只来自该项目/税率命中成本行的所选家族。来源链接验证当前target/key/path，详情返回保留选择与筛选并重读服务端；来源 disclosure 必须进入键盘焦点循环。
- 全量勾选与预览准备分开：首页仅为当前源文件建立作业，名称选择窗和删除清单每组最多100项；完整队列可翻阅或序号跳转，不能截掉100项之后的选择。后台100条批次限制及渲染/缓存/保活边界继续保留；关闭与切换丢弃迟到结果。

## 服务器来源与原型边界（2026-11-19）

[服务器链接设计 §0](../../SERVER_CONNECTION_AND_CACHE_DESIGN.md)列明当前 Vue/后端只读试验版，HTML 原型仍是合成演示。远程预览独立绑定来源/revision/条目版本并复用受限 renderer，不能放宽现有活动目录预览接口；来源根或主机身份异常阻断旧授权。离线副本须标核验时间并由用户明确选择，未缓存不可伪装已预览；XML 只作纯文本。关闭/切换释放对应来源租约，迟到请求不能覆盖新预览；蓝条进度来自对应任务，失败保留完整结果。

子树是否有可读文件以服务器 `scope.readable_files` 为准，计数不受关键词/分页影响；只有不支持格式时保留元信息并提示“无可读取的文件”，筛选无匹配另显。离线列表和已开文件标签均须标“查看离线副本”；重开收藏先回填已保存绑定及预算，再允许保存，不能用默认值覆盖。

生产右栏不创建服务器公司树，不改变本机模块与侧栏上下文；常规和放大宽度均限主内容区，跟随窗口及侧栏拖宽。目录列表按不透明 parent_id 分页，汇总限定该目录含子目录；未连接、失败、筛选为空与完整空目录分开显示。公司绑定只保存身份上下文，现有公司/成本/做账/税费模块明确未接入。前端不保存密码/私钥，不执行远程命令；真实 SMB/SFTP/SSH Agent 与原生选择器不能由合成浏览器验收替代。

服务器原型按最新用户修订：入口“打开服务器文件列表”仅开右侧面板；原目录汇总标签显示当前目录名并提供下拉子目录/面包屑返回，统计限当前目录含子目录。空目录/只有不支持内容显示“无可读取的文件”，未连或请求失败不能当空目录。右上角仅开关/放大还原，普通与放大宽度都限主内容区，跟随窗口与公司栏拖宽；移除全屏和独立服务器公司树，本机模块与侧栏保持原上下文。固定合成示例可持久缓存，自填配置不能写浏览器存储；正式模块 SourceBinding 同代际接入仍为未来能力。详见设计 §4、11—12。

## WS-03 / WS-04 项目列与凭证墙

经典首页项目列必须复用项目汇总优先级，分页后只读附加；人工文件损坏时可诊断并保留发票列表，不把损坏当空覆盖。比较汇总卡片与流水明细只显示后端 steps / record_ids，不自算金额。凭证墙每组最多六项，只有后端带 preview 才可请求；隐藏标签关闭大图、停止续租，恢复重新校验，迟到响应不能覆盖新来源。银行回单独立绑定公司、目录和文件版本，客户端不得传路径、不得借此开放非监控发票。回单大图从对应源页开始；来源不唯一不给预览。

## 工作区 P1 交接（2026-11-17）

目录统计由后端完成全部筛选与同票家族合计，页面兼容一个版本的数字/十进制字符串，不在标签筛选时隐藏金额。公司资料夹路径变更后有界只读检测，迟到响应丢弃；缺目录由用户明确勾选，登记请求携 revision 与身份哈希。登记/导出未知响应必须锁定写按钮并提供查询入口，不能静默重试。导出预览沿用 WsModal、列名胶囊与受限横向表格，浅/深/390px 验收仍必需。嵌入成本的公司口径只读，不提供全局身份编辑替代公司设置。

## P2 结果消费与未知保存（2026-11-17）

标签计数资料不全时用“已知 N 张”并列不可用公司；刷新计数不得覆盖未保存标签编辑。凭证墙只显示后端 flow_match/project 字段，null 不显示未匹配。银行映射修改后必须再校验，错误行与原始行样例可查，断链禁存。税费 null 显示“—”，确认零才显示 0；全部范围明确为已保存记录覆盖期。切换编辑月份先读该月与 revision；未知保存只能查询完整记录/版式哈希，409 刷新但不重放。新弹窗复用 WsModal，窄屏映射控件可达、样例表仅局部横向滚动。

## P3 工作区消费与浏览器切片（2026-11-17）

银行只让未识别文件打开映射；pending/回单/内置/确认状态不冒充空文件。改映射或账号后须再校验。凭证输入时合计仅为即时展示，保存后的后端校验才决定审核；未知保存锁定结构/字段/导出/生成按钮，只有成功读回才能解除，查询失败不重发。库存精简视图保留卖超等异常与明细入口，社保只按所选属期高亮，不从社保费率推算工资。经典做账 frame 首次实际访问才挂载，随后常驻保留状态，避免纯公司草稿/税费页触发无关 active-target 请求。

WS-02 多候选下拉不得默认取第一项；每类明确选择并取得新检测计划后才允许登记，未选择项不发送空映射。WS-05 工资区域只展示后端核对结果，50 行分页、默认脱敏；关闭完整显示立即隐藏旧原值，请求失败也不残留。确认仅提交候选 ID、来源/税文件 revision 与明确费用科目，不提交可伪造的人员行；取消确认也携带 revision。409 刷新但不重放，网络/5xx 结果未知时锁定写入并显示读取结果入口。公司或映射改变时清掉旧工资/弹窗并丢弃迟到响应，工资和社保确认后刷新共享 revision。

`scripts/dev/workspace_p3_e2e.mjs` 使用临时合成目录+真FastAPI/Chromium验收映射、结构保存和税费，不mock HTTP；可本机启动 Chrome，也可用 `P3_E2E_CDP` 连接外部 Chrome（只关闭自己的 context），两种方式的断言相同；默认产物位于 output/playwright/workspace-p3，收尾清理。浅/深/390px/no_skin检查不能代替真实默认配置、Windows BAT、正式入口前台、系统原生选择器或成品验收；工作区两款隔离皮肤不因本轮重新启用。
