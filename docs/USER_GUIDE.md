# InvoiceHub 使用指南

从 [Releases 发布页](https://github.com/lyc1126/InvoiceHub/releases) 下载对应系统的桌面包（Windows x64 便携 ZIP 解压即用；macOS 13+ Apple Silicon 从 DMG 复制 App 后启动），或按 [README](../README.md) 从源码运行。各版本的签名及验收限制以对应发布说明为准。

## 首次启动与多公司工作区

1. **添加公司资料夹。** 首次进入工作区时，按起始页三步引导点击“添加公司资料夹”，可登记已有的公司目录，或在空目录下新建标准六类子目录（成本发票、开具发票、费用报销、银行流水、进项抵扣、工资社保）。
2. **设为监控目录。** 同一时间只有一个活动监控目录。将常用发票目录设为监控目录后，后台会增量解析并维护汇总与成本投影；其他公司目录可在工作区按需点“读取数据 / 更新数据”只读刷新，不会误切监控目录。
3. **零散票临时识别。** 左侧“临时识别”入口可拖入或选取散落 PDF / OFD / XML，结果只留在弹窗历史中，不写入任何公司档案。

## 选择发票目录（经典入口与目录草稿）

1. 将 PDF、OFD、XML 源发票放在你管理的文件夹中。
2. 经典首页点击“选择文件夹”后仅形成“待保存目录”草稿，确认并点击“保存目录”才切换；未保存草稿不会被自动刷新覆盖。
3. 启动和目录切换会在后台同步。需要主动扫描时点击“重新汇总”；成本页“刷新”只读取当前结果，不生成新文件。

## 搜索、勾选、预览与打印

- **搜索与筛选。** 默认搜索销售方和发票号码，“文件名”和“全部范围”可单独选择；列表按页显示，批量全选作用于完整筛选结果，可自定义显示列。
- **同票去重合计。** 勾选后点击“合计详情”按同一 20 位发票号码家族去重，并展示按项目、明细税率、规格与单位分组的明细合计；任一金额冲突会显式标出，不猜数。
- **原票预览与批量打印。** 源文件预览按原页序渲染 PDF / OFD（内置 Java 21 / OFD 组件）与安全纯文本 XML；批量打印使用原始 PDF 票面（选中 OFD/XML 时回退同家族 PDF），多页发票完整保留。打印对话框打开不等于纸张已成功打印。
- **删除边界。** 自动同步绝不删除源发票；勾选并二次确认的“删除所选文件”仅移入系统回收站/废纸篓，不降级为永久删除。

## 成本工作台 V2、单据与四维勾稽

- **成本分析 V2。** 在公司页签打开成本工作台，区分货物与服务双路径成本、采购单价与报价加价、开票参考（保留已开快照）以及公司纳税人身份时间线；也可切换至“经典成本表（v1）”查看监控目录三件套。
- **入库单 / 出库单。** 先预览再导出，超出模板固定行数自动扩行；大目录单据索引支持停止并保留进度。
- **四维勾稽与同号检查。** 在左侧右键两个目录可发起进销存、往来、抵扣勾稽，或对任意两个发票目录（支持跨公司）执行只读同号检查；所有差异与未对上记录均按后端核对结果展开展示。

## 凭证草稿与通用凭证导出

- 在公司页签“凭证草稿”中，可基于发票、银行流水与工资社保生成分录草稿，逐行编辑与审核，并校验借贷平衡与科目可用性。
- 导出默认使用软件无关的 **「通用凭证表（标准）」**（18 列标准 Excel，支持无损读回与二次加工），同时兼容已实测品牌模板及放在 `做账草稿/导出模板/` 下的自定义表头模板。
- 正式账套录入前请务必自行核对科目映射、期间与审核状态。

## 按需接入 PaddleOCR（扫描发票与社保截图）

- 核心包不内置重型本地 OCR 引擎，默认保持关闭（`disabled`），不发送任何外部请求。
- 需要识别扫描件或工资社保截图时，可在左侧「OCR」页选择：
  - **PaddleOCR 官方 API**：填写个人 Access Token（单独加密权限保存在本机 `runtime/.ocr-secrets.json`，不写入普通配置），勾选明确云端同意，并按公司单独授权后才允许上传识别。
  - **PaddleOCR 自建服务**：填写本机或局域网自建 HTTP 接口地址，数据留在内网。
- 识别结果按文件内容 SHA-256 缓存在本机 `runtime/ocr-cache.sqlite3` 中避免重复计费；发票字段会再次经过号码、税率与算术守恒校验，不一致字段留空待核对。

## 只读服务器目录（SMB / SFTP 试验版）

- 侧栏“连接服务器”支持添加只读 SMB 共享或 SFTP（当前试验版仅支持本机已解锁 SSH Agent 公钥认证，不保存密码或私钥）。
- 服务器来源使用独立档案与本地只读缓存预算（自动 LRU 淘汰未固定副本），仅用于浏览、原票预览与独立汇总，绝不向远端写入文件，也不会混入本机公司统计。

## 文件保存在哪里

| 位置 | 内容 |
|---|---|
| 当前发票目录 `watch_dir` | 源发票，以及 `成本发票明细.csv`、`成本发票汇总.xlsx`、`成本开票状态.json` |
| 汇总工作区 `workspace` | 普通汇总、代际投影与监控业务日志（历史代际与解析缓存自动有界回收） |
| 用户运行目录 `runtime` | 配置、任务、事件、OCR 缓存/密钥、服务器只读缓存、导入皮肤与运行诊断 |

源文件是事实，CSV/XLSX/JSON 可以重建；自动删除同步绝不删除源发票。

## 监控、端口冲突恢复与关闭

- 点击“启动监控”，待状态就绪后再持续放入新发票；独立监控与 Web 服务生命周期分离，关闭桌面窗口只隐藏，关闭系统时会询问是否保留监控。
- 桌面端固定使用 `127.0.0.1:8766`。若启动时检测到端口已被另一个已确认的 InvoiceHub 实例占用，会弹窗征求你的确认后优雅关闭旧实例再启动；若占用者身份不明，则拒绝接管并提示排查。
- Windows 源码入口的两个停止命令固定为：
  - `停止一站式发票汇总系统.bat`：只停止 localhost。
  - `停止一站式发票汇总系统并停止监控.bat`：同时停止 localhost 和监控。

## 外观与恢复

- 设置页可切换内置图标、浅色 / 深色外观或导入合规皮肤 ZIP；明暗切换保留草稿与勾选。
- 皮肤异常时在地址后追加 `?no_skin=1` 恢复默认浅色显示，且不改写已保存设置。

## 遇到问题与反馈

- 启动失败时查看托盘“运行状态与启动诊断”或[启动排障说明](STARTUP_TROUBLESHOOTING.md)；Windows 源码目录提供 `检查启动环境.bat`。
- 如需反馈问题或建议，请打开 **设置 › 关于 › 建议与反馈**，点击“复制脱敏信息并打开 GitHub Issue”即可复制版本号与系统架构等脱敏环境信息（绝不包含发票、路径或日志）并跳转 GitHub 提交。

详细诊断见[监控与日志](MONITORING_AND_LOGGING.md)，已知缺口见[迁移清单](MIGRATION_GAP_CHECKLIST.md)。开发入口为[架构总览](DEVELOPMENT_ARCHITECTURE.md)和[任务导航](architecture/AGENT_TASK_MAP.md)。
