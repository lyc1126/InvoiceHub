# InvoiceHub 使用指南

从[发布页](https://github.com/lyc1126/InvoiceHub/releases/tag/v0.3.0-alpha.2)下载对应系统的预览包。Windows x64 版解压使用；macOS 13+ Apple Silicon 版从 DMG 复制 App 后启动。当前预览的签名及验证限制见发布说明。

## 选择发票目录

1. 将 PDF、OFD、XML 源发票放在你管理的文件夹中。
2. 首页点击“选择文件夹”。选择结果只是“待保存目录”，确认后点击“保存目录”才切换。
3. 启动和目录切换会在后台同步。需要主动扫描时点击“重新汇总”；成本页“刷新”只读取当前结果，不生成新文件。
4. 过去保存的目录可再次选择；尚未保存的目录草稿不会被自动刷新覆盖。

## 搜索、核对和汇总

默认搜索销售方和发票号码。“文件名”和“全部范围”可单独选择，文件名参与命中时会显示在结果中。首页按页显示，批量全选作用于完整筛选结果。

勾选后查看合计，按同一发票号码家族去重。某个金额存在冲突时会提示，不强行选一个数。详情页可以打开原文件、查看明细及手工修订；系统不会用文件名随意填补正文提取不到的核心字段。

源文件预览保留所选来源和原页序，不把表格字段拼成新的票面。批量打印使用 PDF，选中同票 OFD/XML 时可使用同家族 PDF；缺少可打印 PDF 会明确提示。打印对话框打开不等于纸张已经打印成功。

## 成本与单据

成本页提供“成本发票明细”“项目规格汇总”“开票参考”“发票校验”。明细保留逐行口径，开票参考按行管理加价率和状态，已开部分保留保存当时的快照。可复制当前表格到 Excel/WPS。

入库单、出库单先预览再导出；超出固定行数时按实际内容展开。批量入库遇到已有文件可选择跳过或导出副本。大目录的单据索引可停止并保留已完成的解析，继续时会检查文件变化。

## 文件保存在哪里

| 位置 | 内容 |
|---|---|
| 当前发票目录 `watch_dir` | 源发票，以及 `成本发票明细.csv`、`成本发票汇总.xlsx`、`成本开票状态.json` |
| 汇总工作区 `workspace` | 普通汇总与监控业务日志 |
| 用户运行目录 | 配置、任务、事件、缓存、导入皮肤和运行诊断 |

这些目录用途不同。以页面显示的实际输出路径为准；成本三件套始终属于当前发票目录。源文件是事实，CSV/XLSX/JSON 可以重建，删除同步不删除源发票。

## 监控和关闭

点击“启动监控”，等状态显示就绪后再继续放入新发票。监控独立于网页服务运行；关闭浏览器不停止监控。

桌面窗口关闭只隐藏。需要退出时使用页面“关闭系统”或托盘 Quit；页面会明确询问是否保留监控。启动方式可在设置中切换为桌面或浏览器，完整退出后下次启动生效。

Windows 源码入口的两个停止命令固定为：

- `停止一站式发票汇总系统.bat`：只停止 localhost。
- `停止一站式发票汇总系统并停止监控.bat`：同时停止 localhost 和监控。

## 外观与恢复

设置中的外观分类可以选择内置图标，皮肤管理页可切换内置皮肤或导入合规的皮肤 ZIP。明暗切换会保留当前草稿与勾选。

皮肤显示异常时，在页面地址后加 `?no_skin=1` 恢复默认无皮肤显示；它不改写已保存的皮肤选择。皮肤 ZIP 不执行 JavaScript，也不改变业务表格或导出文件。

## 遇到问题

启动失败时查看托盘“运行状态与启动诊断”；Windows 源码目录也提供 `检查启动环境.bat`。不要结束无法确认归属的占用进程，也不要让多个版本同时写同一运行目录。

详细诊断见[监控与日志](MONITORING_AND_LOGGING.md)，已知缺口见[迁移清单](MIGRATION_GAP_CHECKLIST.md)。开发入口为[架构总览](DEVELOPMENT_ARCHITECTURE.md)和[任务导航](architecture/AGENT_TASK_MAP.md)。
