# README 截图来源

本目录中的 7 张 PNG 均于 2026-11-27 从 InvoiceHub `v1.0.0` 共享 WebUI 的隔离合成示例环境实拍（1440×900，2x 缩放，默认外观），用于展示 `v1.0.0` 多公司工作区、原始文件预览及新增核心模块的实际界面效果。

- `invoicehub-workspace-home.png`：Vue 3 多公司工作区首页与监控目录（`成本发票`）列表视图，展示公司资料夹树、KPI 汇总卡、同票多格式徽标、标签与项目归属。
- `invoicehub-original-preview.png`：列表行内侧滑原始发票高清预览效果，展示全脱敏合成电子增值税专用发票 PDF 票面、缩放与页码控制。
- `invoicehub-global-search.png`：跨公司全局检索弹窗（`⌘K / Ctrl+K`，WS-11），展示跨公司监控/只读目录多词命中与一键跳转定位入口。
- `invoicehub-file-browser.png`：通用文件管理与导入视图（WS-12），展示子目录切换、无覆盖拖放/选择文件导入、重命名、移动与回收站操作入口。
- `invoicehub-cost-v2.png`：成本分析 V2 的 `毛利分析`（按品类单位）视图，展示 8 个 V2 页签、月末加权平均成本与毛利率，以及未归类服务项如实标示「待核对」的口径。
- `invoicehub-reconciliation.png`：账目核对（`成本发票 ⇄ 开具发票（进销存）`）视图，展示期初/购入/销售成本/期末库存汇总卡、4 项校验成立状态与分品目勾稽明细。
- `invoicehub-vouchers.png`：凭证草稿审核与导出视图，展示借贷平衡校验、分录编辑与审核后导出入口。

## 脱敏与使用边界

- 所有公司名称（如 `星河机电科技有限公司（示例）`、`晨曦建材商贸有限公司（示例）`）、往来方、纳税人识别号、20 位发票号码、品目、金额与备注均为脚本生成的虚构示例数据，原始发票 PDF 票面亦带有明显“示例脱敏票面 · 仅供产品预览”水印。
- 截图运行于完全隔离的临时演示目录与临时本地端口，未读取本机真实配置或真实业务目录，拍摄完成后已清理临时数据；所有图片均已逐张目检，确认不含真实发票、真实主体、凭据或个人本机路径。
- 截图以浏览器页面呈现共享 WebUI 的功能视图，不替代双平台真机安装包验收；后续大型版本更新时应从对应版本重新拍摄并复核脱敏。
