# Privacy Notice

InvoiceHub is designed to process invoices and related files locally. Source
invoices, configuration, generated CSV/XLSX/JSON projections, monitor state and
accounting materials remain in locations selected by the user unless the user
explicitly exports or shares them.

The application does not include product analytics or telemetry. An explicit
update check may request public release metadata from the compiled, allowlisted
HTTPS Feed. That request can expose ordinary network metadata to the hosting
service, such as IP address and user agent, but does not upload invoice content
or local file paths.

GitHub issues, pull requests, release downloads and private vulnerability
reports are governed by GitHub's own policies. Do not attach real invoices,
company data, credentials, or private configuration to public project content.

Future hosted features require a separate privacy review and notice before they
are enabled.
